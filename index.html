ข้อแนะนำความปลอดภัยและการรัดตรึงสินค้า (CTU Code & Cargo Securing)

  • แผ่นยางกันลื่น (Friction Mats): ปูแผ่นยางกันลื่นใต้ฐานม้วนกระดาษทุกม้วน ค่าสัมประสิทธิ์แรงเสียดทาน (μ ≥ 0.6) ป้องกันการไถลตัวขณะเผชิญคลื่นลมในทะเล
  • ถุงลมกันกระแทก (Dunnage Airbags): อุดช่องว่างแนวยาวและแนวขวางที่เกิน 15 ซม. เพื่อล็อกม้วนให้อยู่ในตำแหน่งที่มั่นคงตามมาตรฐาน CTU Code
  • สายรัดคานท้ายตู้ (Lashing Straps & Chocks): รัดตรึงแถวม้วนสุดท้ายฝั่งประตูตู้ด้วยสายรัดโพลีเอสเตอร์และลิ่มไม้ขวางล้อ (Chocks) ป้องกันสินค้ากระแทกบานประตู
  • การกระจายน้ำหนัก (Weight Distribution): จัดวางม้วนกระดาษให้กระจายสมดุลซ้าย-ขวาและหน้า-หลัง โดยจุดศูนย์ถ่วง (CG) รวมต้องไม่เบี่ยงเบนเกิน 5% จากกึ่งกลางตู้

ติดตั้ง RollPack Pro บนมือถือ

ใช้งานสะดวกแบบ Native App เปิดได้แม้ไม่มีเน็ต

สำหรับ iPhone / iPad (Safari)

  1. แตะปุ่มแชร์ ที่แถบด้านล่างของ Safari
  2. เลื่อนลงมาแล้วเลือก "เพิ่มไปยังหน้าจอโฮม" (Add to Home Screen)
  3. แตะ "เพิ่ม" (Add) เพื่อติดตั้งไอคอนบนหน้าจอหลัก

สำหรับ Android (Chrome)

  1. แตะปุ่มจุดสามจุด ที่มุมขวาบนของ Chrome
  2. เลือก "ติดตั้งแอป" (Install App) หรือ "เพิ่มลงในหน้าจอหลัก"
  3. กดยืนยันการติดตั้ง พร้อมเปิดใช้งานได้ทันที
